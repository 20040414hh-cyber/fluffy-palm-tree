# 表现类型扩展词典

依据第三讲第22—38页整理，补充第45—61页涉及的评估轮盘与象形统计。原有三种类型的详细说明继续保存在第二目录。

|类型|主要用途及识别|需要区别|案例分类入口|
|---|---|---|---|
|混合型 Mixed Charts|图表、文字和符号围绕主题组织|多图拼贴未必形成叙事|[混合型](../02-信息图形类型案例/分类导航/02-按表现类型/混合型.md)|
|文字／列表 Informational / List|分组解释与条目浏览|编号不自动表示排名|[文字／列表](../02-信息图形类型案例/分类导航/02-按表现类型/文字型与列表型.md)|
|时间轴 Timeline|呈现事件先后和阶段|等距节点不等于等时长|[时间轴](../02-信息图形类型案例/分类导航/02-按表现类型/时间轴型.md)|
|示意 How-to|说明对象、原料或操作|说明图不必是统计图|[示意](../02-信息图形类型案例/分类导航/02-按表现类型/示意图型.md)|
|流程 Process|步骤依赖、判断和循环|流程与编年不是同一关系|[流程](../02-信息图形类型案例/分类导航/02-按表现类型/流程图型.md)|
|比较 Comparison|同字段并列对照|必须核对单位与口径|[比较](../02-信息图形类型案例/分类导航/02-按表现类型/比较型.md)|
|地标 Location|地点、线路和区域定位|拓扑路线不保证真实距离|[地标](../02-信息图形类型案例/分类导航/02-按表现类型/地标型.md)|
|图片式 Photo-graphic|摄影与量化或注释结合|照片透视不承担统一量值尺度|[图片式](../02-信息图形类型案例/分类导航/02-按表现类型/图片式.md)|
|层级 Hierarchical|父子分支与结构组织|位置高低不一定是组织层级|[层级](../02-信息图形类型案例/分类导航/02-按表现类型/层级型.md)|
|单一图表 Single chart|聚焦一个主要统计关系|一个图也可有叙事|[单一图表](../02-信息图形类型案例/分类导航/02-按表现类型/单一图表型.md)|
|可视化文字 Visualized Text|字体、字块与符号组织语义|字号未必代表词频|[可视化文字](../02-信息图形类型案例/分类导航/02-按表现类型/可视化文字型.md)|
|解剖 Anatomical|对象内部、部件和局部解释|指引线不是数据流|[解剖](../02-信息图形类型案例/分类导航/02-按表现类型/解剖型.md)|
|视觉简历 Visual Resume|经历、教育与技能表达|自评图形需说明依据|[视觉简历](../02-信息图形类型案例/分类导航/02-按表现类型/视觉简历型.md)|
|手稿|用手绘语言表达结构|是风格，不能替代数据逻辑|[手稿](../02-信息图形类型案例/分类导航/02-按表现类型/手稿型.md)|
|编年与编目混合|时间路径与对象目录结合|不同模块可能还有网络和地理|[混合结构](../02-信息图形类型案例/分类导航/02-按表现类型/编年与编目混合型.md)|
|三维 3D|立体结构和空间拆解|透视和遮挡不利精确比较|[三维](../02-信息图形类型案例/分类导航/02-按表现类型/三维型.md)|
|象形统计 ISOTYPE语境|重复图形单元表达统计量|与ISO公共图形标准不同|[象形统计](../02-信息图形类型案例/分类导航/02-按表现类型/象形统计型.md)|
|评估轮盘|比较设计取舍维度|无量表时不是客观评分|[轮盘](../02-信息图形类型案例/分类导航/02-按表现类型/评估轮盘型.md)|

历史地图、关系谱系为本库便于检索增加的标签，见[全部分类](../02-信息图形类型案例/分类导航/README.md)，不声称它们是课件列出的并列类型。常用类型名称不构成互斥集合。
