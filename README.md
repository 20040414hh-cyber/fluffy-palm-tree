## 案例驱动的更新约定

每次新增案例，同步完成案例分析、分类索引、相关A—E条目与类型说明的实质修订，并在被修订条目旁链接具体案例。区分图中观察、分析推断和待验证原则；反例出现时缩小适用条件或撤回结论。更新发生在处理新案例的同一次任务中，尚未配置后台自动分析。
