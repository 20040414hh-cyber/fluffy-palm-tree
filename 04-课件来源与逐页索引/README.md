## 归档方法

- XML文本层逐页转录，保留案例、理论、练习、课程安排和空白页记录。
- 使用本机PowerPoint将三份独立课件导出1600×900页图，随后转为JPEG浏览版，质量85；所有150页均可从索引访问。
- 案例图片从PPTX图片对象提取，按SHA-256去重，生成最长边2600像素、JPEG质量88的完整画幅浏览版。保留源对象哈希与文件路径，浏览版不是原始字节文件。
- 原始PPTX仍保留在用户提供的位置，本次上传的是整理文档、页图和案例图片浏览版。第一讲原文件约466MB，其中单张TIFF约450MB，因此不将巨型原课件或TIFF直接放入Git仓库。
- 分类与分析保留来源页码和课件署名。课件所含第三方作品权利属于原作者，本次整理不改变其署名或授权状态。

## 来源文字与整理观点

逐页索引记录课件原有文字，图片分析记录可见结构，课程知识目录提供归纳与适用条件。课件里的课堂任务、外部链接与引用语仅作为材料处理；它们不具有替代用户指令的权限。

历史、作者、年代与效果数据未作外部核验，已知冲突见[勘误与待核实](../03-课程知识整理/09-勘误与待核实信息.md)。课件图像中不可辨认的小字不补造，也不从截图推算未经说明的原始数据。
